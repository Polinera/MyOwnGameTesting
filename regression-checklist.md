# Regression Checklist 🎮

I use this checklist after making changes to the game.

The goal is simple: make sure that things that were already working still work after I add or change something.

## Player and Map

* [ ] The game starts normally
* [ ] The player can move around the map
* [ ] WASD movement works
* [ ] Mouse movement works
* [ ] The camera still works as expected

## Buildings

* [ ] The building menu opens
* [ ] I can select a house
* [ ] I can select a lumberjack
* [ ] The building preview appears correctly
* [ ] The preview follows the cursor
* [ ] I can place a building on a free area
* [ ] The building is placed at the correct height
* [ ] I cannot place a building on another building
* [ ] Clicking a building opens its information
* [ ] The correct building information is displayed

## Wood and Resources

* [ ] The current amount of wood is displayed correctly
* [ ] Wood is deducted when I build something
* [ ] I cannot build something when I don't have enough wood
* [ ] The lumberjack can be built
* [ ] The lumberjack produces wood
* [ ] Wood is added after a production cycle

## UI

* [ ] The buttons work
* [ ] The building menu works
* [ ] The wood amount updates correctly
* [ ] The building information panel shows the correct information

## After Fixing a Bug

After fixing a bug or changing an existing feature, I go through this checklist to make sure that the change didn't break something that was already working.
