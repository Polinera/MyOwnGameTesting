# My Own Game Testing

This is a small QA project based on a cozy game I’m currently developing in Unity.

I’m using my own game as a way to practice testing in a real project — creating test cases, exploring different game mechanics, finding bugs, and thinking about how the game feels from a player’s perspective.

## What I’m testing

* Player movement and interactions
* Resource gathering
* Inventory
* Building mechanics
* UI and menus
* Game rules and edge cases
* NPCs and other gameplay systems as they are added

## What you’ll find here

* Test cases
* Bug reports
* Exploratory testing notes
* Regression checklists
* Testing ideas and observations

The game itself is not included in this repository. This repository focuses on the QA and testing side of the project.

## Project status

This is an ongoing personal project.
The game and the testing documentation are being developed step by step.
