# BUG-001 — Incorrect Building Name or No Response on Click

**Severity:** Medium
**Status:** Fixed

### What happened

When clicking on a building that was already built, an information panel should appear with the name of the selected building.

Instead, two problems could occur:

* the panel showed the wrong building name, such as "House", even when a different building was selected;
* sometimes clicking the building did nothing and the panel did not appear.

### Steps to Reproduce

1. Build a building.
2. Click on the completed building.
3. Check the information panel.
4. Repeat the test with another building.

### Expected Result

The information panel opens when a building is clicked and shows the correct name of the selected building.

### Actual Result

The panel sometimes displayed the wrong building name or did not appear at all.

### Status

Fixed. The building selection and displayed building information now work correctly.

Root Cause
The buildings were created using the House prefab as a base. Both the parent object and the House element had their own Mesh Collider and script. Because of this, clicking a building could hit the wrong object and return incorrect building information.

Fix
I moved the collider and building interaction logic to the correct object structure and removed the duplicate components. After the change, clicking a building consistently opens the information panel for the selected building.
