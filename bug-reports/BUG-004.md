# BUG-004 — Wood Amount Was Not Displayed Correctly

**Severity:** Medium
**Status:** Fixed

### What happened

The `ResourceManager` contained wood, but the UI still displayed `0`.

For example, when the wood value was set to `50` in the `ResourceManager`, the UI continued to show `0`.

### Steps to Reproduce

1. Set the wood amount in the `ResourceManager`.
2. Start the game.
3. Check the wood amount displayed in the UI.
4. Compare it with the value stored in the `ResourceManager`.

### Expected Result

The UI displays the current amount of wood stored in the `ResourceManager`.

### Actual Result

The `ResourceManager` contained wood, but the UI displayed `0`.

### Status

Fixed. The UI now displays the correct wood amount.
